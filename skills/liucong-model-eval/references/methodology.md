# 方法来源与复杂档验收

方法参考刘聪公开模型测评文章中的同题对比与真实运行思路。本题库是依此新制的演示题，不宣称是其完整私有题库。

可复用的方法：同题对比；视觉老题回归；工具辅助条件单列；一句话网页/3D/游戏开发；既有项目功能补全；真实运行、截图反馈、修复后复测；保留首轮与迭代成本。

复杂档必须包含真实产物与功能验收，不以“生成代码”作为通过：

| 类别 | 检查维度 | 必需证据 |
|---|---|---|
| 视觉与空间 | 原图细节、几何/遮挡/空间关系；纯模型与工具辅助分别记录 | 原图、答复、可核对答案、工具轨迹 |
| 前端/3D/游戏 | 核心玩法或业务闭环、交互、视觉与还原度、窄屏、错误反馈 | 页面、操作过程、首轮问题与修复前后 |
| 后端/真实修 bug | 协议、参数与异常、状态迁移、幂等、持久化、回归 | 原始代码、实际请求和测试输出、重启验证 |
| 长程任务 | 目标保持、工具选择、自行验证、修复效果、耗时与人工反馈 | 完整事件日志与各轮产物 |

演示时间预算：简单每题 120 秒，中等每题 360 秒，复杂每题 420 秒。超时标记超时，不等同于能力上限。对比模型采用相同题面、工具、输入素材和预算；不同档位不合并排序。

第一轮结果不能被后续修复覆盖。重试不挑最好看的那一轮；报告必须列明重试次数和原因。未做的操作、没有的数字不回填。


## v2题源与停止口径

官方benchmark子集、私有题、自制演示题分别报告；来源和题面/图像哈希随runId保存。CLI启动/上游连接准备检查不计分。自动评分只是约定口径，不是官方评分器的替代品。

准备检查未通过或接口执行报错时，本批次停止，先读错误再决定补跑。超时保留timeout与已生成文件，不能直接认定是模型能力上限。GUI/听感/指针拖动未做即标未测。
